# Product Onboarding

## Product Positioning

Shandong is an investment research / quant research SaaS demo. It is designed to show research workflows, readiness, risk context, reports, admin controls, and platform planning. It is not an automatic trading system.

## First-Run Experience

When a user opens the product for the first time:

1. Look at onboarding.
2. Open dashboard.
3. Use demo login.
4. Open admin console.
5. Review safety boundaries.

## What Users Can Do

- View demo dashboard.
- Review system readiness.
- Test demo login.
- View admin console.
- Review API docs.

## What Users Cannot Do

- Cannot place trades.
- Cannot connect broker.
- Cannot use real payment.
- Cannot use production identity.
- Cannot deploy to production cloud yet.

## Demo Script

Start with the Onboarding page and explain that Shandong is a research-focused SaaS demo. Open Dashboard to show status and safety boundaries. Use Demo Login to select Admin, then open Admin Console to review identity planning, observability, deployment dry run, and release candidate status. Finish in API Docs and repeat that the system is local/demo only: no broker, no automatic trading, no real payment, no production identity, and no production cloud.
