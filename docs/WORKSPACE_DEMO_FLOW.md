# Workspace Demo Flow

## Workspace Concept

A workspace is the SaaS multi-tenant unit. It groups roles, quota, usage, reports, and admin views under one demo customer boundary.

## Demo Workspace Flow

1. Open onboarding.
2. Login as admin.
3. Open workspace demo.
4. Explain roles.
5. Explain quota.
6. Explain usage.
7. Explain reports.
8. Explain safety boundaries.

## What Is Demo Only

- customer

- reports
- membership
