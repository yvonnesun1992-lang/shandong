# Shandong Quantitative System Brand Guide

## Brand

- English name: Shandong Quantitative System
- Chinese name: 山洞量化系统
- Logo: gold mountain candlestick style
- Mode: brand_system_only
- Theme: institutional_quant

## Logo Asset

- Frontend asset: `/brand/shandong-quant-logo.png`
- Source-controlled reference: `brand_system/assets/shandong-quant-logo.png`
- The selected logo is the deep navy + gold mountain/candlestick version.

## Color Palette

- Primary deep navy: `#0B1F3B`
- Gold accent: `#C8A24A`
- Background: `#061525`
- Surface: `#0E2746`
- Soft surface: `#132F52`
- Text: `#F6F2E8`
- Muted text: `#B9C2D0`

## Typography

- Use Inter/system UI fonts.
- Keep headings strong and compact.
- Keep letter spacing at `0`.

## UI Tone

- Institutional financial platform.
- Bloomberg-like density and contrast.
- No playful, cartoon, neon, or cyberpunk styling.
- Cards use subtle radius and high contrast.
- Buttons are minimal and solid.

## Safety

Branding changes do not enable broker access, sandbox API access, credential reading, account reading, balance reading, position reading, order preview, order submission, or real-money execution.
